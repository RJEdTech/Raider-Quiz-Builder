Importing into Canvas

Two doors, and they land in two different places. Pick the one that matches the quiz engine you want.

New Quizzes
Build → ⋮ → Import Content
  1. Quizzes → + Quiz → New Quizzes → Save. You need a quiz open before you can import into it.
  2. On the Build page, open the ⋮ menu (top right) → Import Content.
  3. Drag the .zip in, or Browse → Import.
  4. Wait for the status bar, then preview before publishing.
Items land in the quiz you currently have open — so start from a blank one, not a quiz you care about. New Quizzes accepts QTI 1.2, which is what this tool produces.
Classic Quizzes
Settings → Import Course Content
  1. In your course, Settings → Import Course Content (right sidebar).
  2. Content Type: QTI .zip file — not Common Cartridge.
  3. Choose your .zip → Import.
  4. The quiz appears in Quizzes, and its questions in a question bank.
This is a course-level import, not a New Quiz. Unless your Canvas admin has turned on New Quizzes Migration During Course Import/Copy, you get a Classic quiz plus a question bank — which is the right answer if you use LockDown Browser's Classic workflow, and the wrong one if you wanted a New Quiz.
Either way, preview before you publish. A few things convert differently between the two engines:
  • Feedback. Multiple-choice and true/false feedback works in both. Feedback on multiple-answer, essay, and file-upload questions renders in Classic only — New Quizzes drops it silently.
  • Numerical tolerance. Margin-of-error (= 3.142 +- 0.001) doesn't reliably round-trip into New Quizzes. Use the range form (= [99, 101]) if you're targeting New Quizzes.
  • GROUP blocks. Random draws are a Canvas Question Group, a Classic Quizzes construct. Check the imported New Quiz to confirm the draw survived; if it didn't, import the same .zip into an item bank instead and use Add from Item Bank → Randomized.
